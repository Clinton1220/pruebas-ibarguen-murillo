# Pruebas de Software - Proyecto Cocina

Este repositorio agrupa plan, ejecución y evidencias de todas las fases de pruebas sobre el sistema web **Cocina**, desarrollado en PHP, HTML, JS.  
Incluye: pruebas unitarias, funcionales, de API, base de datos y seguridad.

## Estructura
- Planificación, criterios de aceptación
- Checklists
- JUnit, Selenium, Postman
- Scripts SQL adaptados a la base cocina_db
- Evidencias con fecha/hora visible (capturas y video)

## Proyecto base
- **Sistema:** Cocina - Tienda de utensilios
- **Base de datos:** [cocina_db.sql](05-base-de-datos/cocina_db.sql)
- **Lenguajes:** PHP (backend), HTML, JavaScript, CSS
